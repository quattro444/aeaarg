# Campionato Ping Pong

1. Installa Node.js (versione LTS) da nodejs.org
2. Copia `.env.local.example` in `.env.local` e inserisci URL e anon key
   (Supabase -> Project Settings -> API). Usa SOLO la chiave "anon public", mai la service_role.
3. Nel terminale, dentro questa cartella: `npm install` poi `npm run dev`
4. Apri http://localhost:3000
